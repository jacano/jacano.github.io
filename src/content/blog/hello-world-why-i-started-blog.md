I have been building software for 15 years. I kept explaining the same lessons to new teammates, so I decided to write them down here.

I write about:

- Web3 security and posture management.
- .NET, C++ and native interop.
- Architecture and technical leadership.

Some posts are technical. Others are about leading a team. They cover the things I wish I had found earlier in my career.

The site uses Astro and GitHub Pages. The code is open at [jacano.github.io](https://github.com/jacano/jacano.github.io). Thanks for reading.
